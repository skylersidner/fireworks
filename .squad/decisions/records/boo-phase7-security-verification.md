### Carried F2 bypass list: accepted as residuals; Toad does not need to close them
`router['navigateByUrl'](x)` and `navigateByUrl?.(x)` move only within the SPA's own routes, never to script. `top.location = x`, `location.search = x` and bare `open(x)` could at worst navigate to a `javascript:` URL. The enforced `script-src 'self'`, which has no `'unsafe-inline'`, now blocks `javascript:` navigations, and `frame-ancestors 'none'` means `top` is always us. What remains is an open redirect that needs deliberate obfuscated code past review. `ping`: CSP governs `<a ping>` with `connect-src 'self'`, so it can't reach another origin. The CSP is the backstop for all six. **Boundary:** if the CSP is ever widened in `script-src` or `connect-src`, reopen this list.

### Findings
- **F1 [low, ledger accuracy] `Program.cs:124` / `ApiCacheControlLedgerTests`.** The exception handler is a fifth Cache-Control writer. An `/api` 500 sends `Cache-Control: no-cache,no-store` (plus `Pragma` and `Expires: -1`), not `no-store`. Bowser's record lists four writers, and the "exact ledger" never sees a 500: the forced 500 in `ResponseHeaderTests` checks only the site-wide set. Security impact: none (`no-store` is present). The ledger claim is wrong, though, and a future writer could hide behind it. **Fix:** Bowser adds the 500 row to the ledger with the framework's value (or normalizes it to `no-store`) and lists the exception handler as a writer. Toad confirms the row fails when the value changes.
- **F2 [info] `Services/Health/HealthEndpoints.cs:70-86`.** Orphaned readiness probes during a DB stall hold a pool slot and socket for up to Npgsql's `Timeout` (15 s default). That is up to about 120 a minute per IP, the same as any other DB read during a stall. Measured: 60 orphans released in 3 to 6 s, no leak. **No change needed.** If Railway ever shows pool pressure during an outage, set `Timeout=5` in the production connection string.
- **F3 [info, verifier] `src/app/embedded-shell-reads.spec.ts` (`SHELLS_INDEX`).** The guard matches only `.shells[`, while S15 asked for `shells[`. An alias read (`const { shells } = show; shells[key]`) or `doc['shells'][key]` passes it. All current alias reads are safe (above). **For Toad, optional:** widen the pattern to `\bshells\s*(?:\?\.)?\s*\[` and `\[['"]shells['"]\]\s*\[` with the existing ledger.
- **Not a finding:** my first Chromium run stalled after `/s/ZZZZZZZZ`. The same five-path sequence then ran cleanly in under 3.2 s per path with timeouts (`boo-c1c.mjs`), so the stall was the harness, not the app.
