## Learnings

### 2026-11-13 — Phase 4 fix round (Boo F1/F2/F4/F5, Yoshi D1-D3, Toad)
- **`Services/ControllersRegistration.cs` `AddFireworksControllers()`** is the only `AddControllers()`; Program.cs and `FireworksApiHarness` both call it. It removes the three form value provider factories and adds the API assembly part (dedup-checked). Form bodies were reaching MVC's binders before the gate.
- **`ApiResponseHeaders` sends `Connection: close`** on any `/api` response whose declared `Content-Length` exceeds the current `MaxRequestBodySize` (403, 415, 429 and catch-all 404 included, not only 413). Found because the extended gate test failed 6/6 in isolation (it passed in the full suite by timing). Chunked bodies are not covered. Boo reviewed it.
- **`UpdateOwnedAsync` marks four properties** (`Name`, `SchemaVersion`, `Palette`, `Document`) instead of `State = Modified`, because writing every column put back a stale `remixed_from_id` after `ON DELETE SET NULL` and the UPDATE failed the FK. Marking any property still bumps `updated_at`. A concurrent DELETE (`DbUpdateConcurrencyException`) is re-checked against the desired state and becomes 404.
- **`ICreationRepository.TryInsertAsync` returns `InsertOutcome { Inserted, ShareCodeTaken, RemixSourceGone }`.** On a failed insert the repository asks, in order: does my row exist, is the remix source gone, is the code taken; else rethrow. `RemixSourceGone` maps to the fixed 404. No SQLSTATE matching.
- **Logging:** `Microsoft.EntityFrameworkCore.Database.Command` is `Warning` in `appsettings.json` (Boo F4). README states chunked framing counts toward the limit (F2) and one replica only until migrations take a lock (F5, `42P07`).
- Race tests: `Creations/CreationSourceDeletedMidWriteTests.cs` (SaveChangesInterceptor deletes the source). Form tests: `Creations/FormBodyGateTests.cs` (`FormBodies.All`, shared with `CreationWriteGateTests`).
- Counts: build 0 warnings; plain `dotnet test` 555 passed, 10 skipped; `FIREWORKS_TEST_POSTGRES` 565 passed. Mutants (scratch copy), each killed: providers restored (15 tests fail), whole-entry Modified (D1 test), no property marks (identical-update test), no source-gone check (D2 test), no `Connection: close` (header test), remix never storing `RemixedFromId`. Marking `Palette` alone is an equivalent mutant. Script: session scratchpad `mutants-p4fix.py`.
- Lesson: run a newly extended test in isolation a few times, not only in the full suite; pooled-connection bugs hide behind timing.
