- **Validator traps (Phase 3):** name length counts code points (`string.EnumerateRunes()`), never `Length`. The C# walker mirrors normalize's paths, kinds and codes exactly. Measured on .NET 11: `TryGetDouble` is true with Infinity for `1e400` (check `double.IsFinite`); `AllowDuplicateProperties=false` throws with no path (detect duplicates in the walker, last value wins); `GetString`, `JsonProperty.Name` and `ValueEquals` throw on lone surrogates (gate with `Utf8.IsValid`); `.NET $` matches before a trailing `\n` (use `\z`). Body: read `Request.Body` in the action, not `[FromBody] JsonElement`. Postgres 18.6 `jsonb` rejects `\u0000` and lone surrogate escapes, keeps the last duplicate, and `varchar(80)` counts characters. Worst-case show (1000 cues, 32 shells) is 78.9 KB and validates in 5–8 ms. Record: `decisions/records/bowser-phase3-validator-feasibility.md`; skill `skills/cross-language-validator-parity`.

### Folded from Phase 4 (summarized 2026-11-14)

- **Measured traps:** Postgres's default collation sorts `'a' < 'B'`, so share_code needs `COLLATE "C"`. EF SQLite can't ORDER BY `DateTimeOffset` (a model-only converter in `FireworksDbContext`). The list reads `Request.Query` directly, because `[FromQuery] string?` mangles `kind`.
- **Writes:** `UpdateOwnedAsync` marks four properties instead of `State = Modified`, so a stale `remixed_from_id` isn't written back. `TryInsertAsync` returns `InsertOutcome { Inserted, ShareCodeTaken, RemixSourceGone }`. Timestamps truncate to whole microseconds (`ApplyTimestamps`).
- **Connection and logging:** `ApiResponseHeaders` sends `Connection: close` on any `/api` response whose declared `Content-Length` exceeds the limit. Chunked bodies are not covered (Phase 7). `Microsoft.EntityFrameworkCore.Database.Command` is `Warning` in `appsettings.json`.
