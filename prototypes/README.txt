# Fireworks Prototype - Parity Oracle

## File

fireworks-prototype.html
  The original single-file PixiJS 8.23.0 prototype. Open it directly in a modern
  browser; it loads PixiJS from jsDelivr and needs no build step.

## Role

This file is the visual and behavioral parity oracle for the Phase 2 engine port
and Shell Designer (see plans/initial-implementation.md). Every preset, mode,
Replay, Clear, resize and JSON Copy/Apply behavior in the Angular app is checked
against it. Departures from it are deliberate and recorded as decisions.

## Rule

Do not edit this file. It is a fixed reference; change the app, not the oracle.
Background on the prototype is in docs/fireworks-app/context.md.
