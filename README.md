# Fireworks Sandbox

A web app for designing, saving, sharing and playing fireworks shells (and later timed shows) in the browser. It is built from the single-file PixiJS prototype in `prototypes/fireworks-prototype.html`, on Angular 22 + PixiJS 8, a .NET 10 API and Postgres 18, deployed on Railway.

- **Plan:** [`plans/initial-implementation.md`](plans/initial-implementation.md) is the source of truth for phases, scope and "Done when" criteria.
- **Background:** [`docs/fireworks-app/context.md`](docs/fireworks-app/context.md).
- **Team:** work is coordinated as described in [`CLAUDE.md`](CLAUDE.md); the team is defined in `.claude/agents/` with its memory, decisions and skills in `.squad/`.

**Status:** Phase 0 complete; Phase 1 next.

This README is a placeholder. The full version (dev loop, negative-control table) is Phase 1's deliverable.
