# Phase 2 acceptance criteria: Engine port and Shell Designer

Owner: Peach. Written 2026-11-12 at Phase 2 planning; updated the same day for Skyler's rulings (now in plan Phase 2c/2d), Luigi's 2a/2b findings (`.squad/decisions/records/luigi-phase2ab-engine-and-stage.md`) and Rosalina's 2c design-review (`docs/fireworks-app/design/designer-2c.md`, cited as `2c-spec §N`). Updated 2026-11-13 for Skyler's draft rulings (plan 2c "Purpose of the draft", `.squad/decisions/README.md` §5): a dirty flag replaces the baseline snapshot, the flashing notice pauses playback, held Space fires once. Updated again 2026-11-13 to close Q8 and align 2c.18 with 2c-spec §7.2 as built. Updated a third time 2026-11-13 for Skyler's later rulings (plan 2c, plan §6): a preset or Apply asks only when it would replace a shell or sky change (display settings and the tab never count, reversing Q8(a)), and fps is benched to the end of the project (2d.4 removed).
Source: `plans/initial-implementation.md` Phase 2 (2a–2d), §3.1–3.3, §5. Oracle: `prototypes/fireworks-prototype.html` (cited as `proto l.N`). Where Rosalina's spec lists a deliberate departure (2c-spec §9), the departure is the pass condition, and the parity row says so.

Every criterion is observably true or false. Each one names the **surface** that proves it: a file, a spec, or the running app. "Spec" means a Vitest spec under `src/web/fireworks-web/src/`. "Running app" means `ng serve` (or the built image) in a real browser. Where a check needs a negative control (`toad-verify-the-verifier.md`), the control is stated.

Abbreviations: **W** is the world height (800), **G** is the ground line (760), **S** is the stage's CSS height in pixels.
